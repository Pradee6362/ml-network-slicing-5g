# ML- Based Network Slicing for 5G Networks 

This mini project focuses on analyzing machine learning-based network slicing techniques for 5G networks using MATLAB. The project evaluates the performance of different ML models for efficient network slice management and resource allocation.

## Objectives
- Study ML-based network slicing approaches in 5G networks
- Compare the performance of network slices such as:
  - eMBB
  - URLLC
  - mIoT
- Evaluate model accuracy using confusion matrices
- Analyze computation time and performance metrics of different ML algorithms

## Technologies Used
- MATLAB
- MAchine Learning
- 5G Network Slicing 

## Included Files 
- MATLAB source code
- Dataset files
- Performance comparision graphs
- Confusion matrices
- Computation time amalysis results
